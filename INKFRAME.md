# Inkframe

Inkframe is a 2D animation tool built as a fork of [Tahoma2D](https://github.com/tahoma2d/tahoma2d), developed as an internal art/animation tool for the game **Aetherfall** and for hand-drawn animation work (frame-by-frame, cutout/mesh rigging, and cel-style effects) without the frame limits of commercial tools.

- Based on Tahoma2D — Copyright its contributors — which is itself based on OpenToonz, Copyright (C) DWANGO Co., Ltd. and contributors. See `LICENSE.txt` (BSD-3-Clause); all upstream copyright notices are retained.
- Upstream remote is kept (`upstream` = tahoma2d/tahoma2d) and fixes are merged in periodically.

## Inkframe-specific changes (running list)

- `Inkframe` room set (Draw / Effects / Timing / Files) as the default workspace
- First launch opens maximized when no saved window geometry exists
- `clipstudio` keyboard shortcut preset (Clip Studio Paint muscle-memory drawing keys)
- Autosave enabled by default (10 min)
- Window title / About / startup popups branded Inkframe
